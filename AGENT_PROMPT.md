# промпт для агента: Project Garden

сделай локальный ботанический сад для проектов, заметок и следующих шагов. пользователь добавляет растение вручную или импортирует JSON/ZIP с метаданными, а приложение показывает проект как живой силуэт: рост, пауза или архив.

## готовый сценарий

- название, описание, цвет, состояние, дата обновления, заметка и следующий шаг;
- поиск по проекту и файлам, сортировка по дате, названию и состоянию;
- фильтры роста, паузы и архива, дублирование и удаление;
- IndexedDB с локальным зеркалом, импорт JSON/ZIP, экспорт JSON/PNG;
- ZIP читается только по центральному каталогу: приложение не распаковывает и не выполняет содержимое;
- пустой сад и пустой результат поиска объясняют следующий шаг;
- обычный file picker остаётся рабочим без дополнительных браузерных API.

## визуальный голос

ботанический атлас, молочный фон, мох, шалфей, терракота и охра. Fraunces — для заголовков и названий растений; Azeret Mono — для дат, состояний, путей и технических меток; системный sans — для длинного описания.

русские начала предложений и обычных пунктов списка — со строчной. собственные имена, бренды, аббревиатуры, URL, пути, код и точные цитаты сохраняют свой регистр. текст спокойный, прямой и конкретный, без рекламного тумана и искусственной драматизации.

растения — плоские SVG-силуэты с несколькими формами. не добавляй градиенты, glassmorphism, декоративные баблы, pill-навигацию, бесконечные карточки, bento-сетки, KPI-плитки и CTA ради CTA.

## технические границы

- статический сайт для GitHub Pages без backend, авторизации, API-ключей и внешней AI-модели;
- пользовательские файлы обрабатываются только в браузере;
- не выполнять код из импортированных файлов;
- сохранять доступность клавиатуры, видимый focus, reduced motion, live-region и понятные ошибки;
- проверять desktop, 320px и GitHub Pages.
